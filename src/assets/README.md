# Assets

Imagens e outros arquivos estáticos importados pelos componentes React.

## Arquivos

- `salao-feminino-masculino.png`: primeira imagem do carrossel da tela de acesso.
- `salao-feminino-masculino-2.png`: segunda imagem do carrossel.
- `salao-feminino-masculino-3.png`: terceira imagem do carrossel.

As três imagens são importadas por `components/AuthenticationLayout.jsx`. Ao substituir uma imagem, preserve uma proporção semelhante para evitar cortes inesperados pelo `object-fit: cover`.
